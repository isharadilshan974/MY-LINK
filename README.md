# MY LINK V2 — Next Level

MY LINK is a Social-to-Business operating platform:
**Social Media → Campaign → Smart Link → Lead → CRM → AI → Analytics → Creator → Revenue**

## Included
- Premium responsive Streamlit interface
- English / Sinhala / Tamil language switcher
- Dashboard
- Lead CRM, search, filters, status pipeline, follow-ups and notes
- Campaign Studio and unique Smart Links
- Social source attribution
- Analytics with interactive charts
- Explainable local AI-style lead scoring
- Creator/referral foundation
- Team management
- Notifications
- Settings and deployment health
- SQLite local database
- Demo data on first run only
- Streamlit Cloud + GitHub ready

## Run
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Production upgrade
For real businesses, migrate SQLite to PostgreSQL/Supabase, use managed authentication, object storage, secure secrets, rate limiting, audit/security controls, backups, consent/privacy controls and official social/payment provider APIs.

Note: A Streamlit web app is not an Android APK, so an exact 20 MB app size is not a meaningful deployment target. This project is kept lean and fast rather than artificially padded.
